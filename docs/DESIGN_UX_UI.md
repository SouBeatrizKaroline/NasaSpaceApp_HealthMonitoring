# Interface Design Rationale

## Visual direction

A calm mission-console interface uses deep navy backgrounds, clear light text, cyan interaction cues, and restrained amber review accents. It avoids decorative alarm colors except where the responsible mission configuration defines their meaning. No agency insignia is included, and the page identifies itself as an independent educational prototype.

## Interaction principles

- Put the current mission context and purpose near the top.
- Keep check-in steps short and scannable.
- Use explicit units and source labels for measurements.
- Distinguish unknown, not measured, and zero.
- Offer keyboard operation, visible focus, and readable text at varied screen sizes.
- Do not rely on color alone to convey a state.
- Keep optional well-being and media fields clearly voluntary.
- Show what is saved locally and give export and clear controls.
- Never turn a visual state into a diagnosis or fitness decision.

## Accessibility and environment

Future evaluation should include keyboard-only access, screen-reader labels, reduced motion, glare and low-light conditions, one-handed operation, gloves, floating posture, restrained posture, and limited display sizes. Larger touch targets and a simple offline navigation model should be tested with crew representatives.

## Language support

The interface offers English, Spanish, French, and Portuguese. English is the primary project language. Clinical translations need review by fluent domain professionals before any operational use.
