# Crew Health Check visual identity

## Positioning

A personal health workspace for crew members recording changes across mission stages. The interface emphasizes continuity, individual context, and readable records.

## Design system

Use a light canvas (#F3F6F4), white surfaces, dark green text (#173830), and one primary green (#17634F). Reserve muted red for deletion. Gravity cards share the same palette and identify selection with fill and text. Use Inter when available with Segoe UI and system sans-serif fallbacks. The application requires no remote font request.

Use a consistent type scale, generous whitespace, subtle borders, and a single primary action per form. Keep field labels visible. Contextual instructions sit beside the relevant controls. Retain keyboard focus and touch targets of at least 44 pixels.

## User journey

The opening screen presents the product purpose and profile access together. Opening a profile compacts the introduction and reveals the mission workspace. Desktop navigation follows the check-in and history workflow. Mobile layouts stack fields and provide anchor navigation.

Operations and research are expandable secondary areas. Links to their content open the appropriate area. The mission comparison and report remain attached to the selected profile and mission.

## Validation

Check profile creation, reopening, switching, check-in submission, history filtering, comparison, report export, language changes, media previews, operational planning, and research navigation at desktop and mobile widths. Inspect focus, text wrapping, and long user-entered content.
