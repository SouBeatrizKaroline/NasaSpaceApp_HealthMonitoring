# Mission Standards and Gravity Context

This file records the project's evidence boundary. It does not state or imply NASA approval, certification, compliance, or endorsement.

## Standards to review with mission authorities

NASA-STD-3001 includes human-system requirements for spaceflight. Applicability depends on program and mission, including hardware, software, operational concept, and the responsible authority's tailoring. OCHMO-STD-100.1A concerns astronaut medical certification processes and should not be treated as a software checklist.

Before any real mission use, responsible authorities would need to map requirements to system functions, verification evidence, human factors, medical operations, data protection, and vehicle interfaces. This educational prototype has not completed that work.

## Gravity context in this prototype

The check-in records mission phase and a crew-selected environment (microgravity, partial gravity, or higher-gravity transition). It asks about symptoms and task effects over time. It does not calculate gravity-specific clinical thresholds or infer causes. The five hazards can interact, so event records should retain multiple context fields and their sources.

## Presentation and attribution

NASA source material is cited for context. NASA insignia, seals, and marks are not included. The project's independent status should remain visible in presentations, demonstrations, and repository descriptions. Follow NASA and Space Apps terms for attribution, permissions, and event participation.
